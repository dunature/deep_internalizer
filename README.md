## 🏗️ 架构：双层认知漏斗

Deep Internalizer 使用**双层认知漏斗**将原始文本转化为内化知识：

```mermaid
graph TB
    %% 文档导入
    Import["📄 文档导入<br/>(PDF/DOCX/TXT)"] --> Parse["🔍 AI 文本清洗<br/>(移除噪声、格式化)"]
    Parse --> L0["🌍 Layer 0: 战略地图"]
    
    %% Layer 0: 全局分析
    L0 --> Thesis["📌 核心论点<br/>(ExtraBold 锚点)"]
    L0 --> Chunks["🧩 语义切片<br/>(120px 紧凑磁贴)"]
    
    %% Layer 1: 沉浸循环
    Chunks --> L1["🎯 Layer 1: 沉浸循环"]
    
    L1 --> Step1["1️⃣ 宏观语境<br/>(两栏式全景)"]
    L1 --> Step2["2️⃣ 词汇构建<br/>(50px 超大标题卡片)"]
    L1 --> Step3["3️⃣ 表达训练<br/>(意群切分 + TTS)"]
    L1 --> Step4["4️⃣ 心流练习<br/>(17px/1.6 沉浸版式)"]
    
    %% 进度追踪
    Step4 --> Progress["✅ 进度追踪"]
    Progress --> Review["📚 词汇复习<br/>(间隔重复)"]
    
    %% 样式
    classDef importNode fill:#667eea,stroke:#764ba2,stroke-width:2px,color:#fff
    classDef layer0Node fill:#f093fb,stroke:#f5576c,stroke-width:2px,color:#fff
    classDef layer1Node fill:#4facfe,stroke:#00f2fe,stroke-width:2px,color:#fff
    classDef outputNode fill:#43e97b,stroke:#38f9d7,stroke-width:2px,color:#fff
    
    class Import,Parse importNode
    class L0,Thesis,Chunks layer0Node
    class L1,Step1,Step2,Step3,Step4 layer1Node
    class Progress,Review outputNode
```

## 🚀 性能与稳定性增强

- **瞬间跳转 (Zero Latency)**：通过 `PrefetchService` 实现关键词后台预取，Layer 0 到 Layer 1 的切换感官延迟 < 100ms。
- **稳健性修复**：修复了旧版中存在的页面空白 (Whiteout) 根因、Explore Map 按钮路由失效以及 CSS Module 样式冲突等技术债务。
- **智能音频缓存**：词汇与音节级缓存将 TTS 调用减少了 90%，并提供顺滑的 Syllable-by-Syllable 播放体验。

## 🛠️ 快速启动（推荐开发模式）

为获得完整体验，建议在本地同时启动以下 3 个核心服务：

### 1. 安装环境
```bash
# 克隆仓库
git clone https://github.com/your-repo/deep-internalizer.git
cd deep-internalizer

# 安装前端与 Bridge 依赖
npm install
cd bridge && npm install && cd ..
```

### 2. 配置环境
创建 `.env.local` 文件：
```bash
VITE_LLM_PROVIDER=deepseek
VITE_DEEPSEEK_API_KEY=你的_API_密钥
```

### 3. 一键启动 (3 终端同步)
```bash
# 终端 1：React 前端 (Vite)
npm run dev

# 终端 2：Bridge Server (Node.js) - 负责分析与缓存
npm --prefix bridge run start

# 终端 3：TTS Server (Python) - 负责高保真语音
./scripts/start_tts.sh
```
